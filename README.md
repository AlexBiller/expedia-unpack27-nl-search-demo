# Natural-language rental search prototype

> **Unofficial demo built with Devin - synthetic data.** This project is not affiliated with or endorsed by Expedia Group.
> Every listing, review and evaluation label is fictional and generated by `seed.py`. It uses no real customer data and no credentials, and it does not call any Expedia, Hotels.com or Vrbo system.

**Live demo:** https://alexbiller.github.io/expedia-unpack27-nl-search-demo/

## What it shows
This is a small prototype of AI natural-language search for vacation rentals. The idea comes from public news: Expedia Group's *Unpack '27* travel-trends release and Vrbo's AI natural-language search launch. The demo covers four interactions and takes under five minutes to walk through:

1. **Search seeded records in plain English** (tab 1). Example: *"Romantic cabin with a fireplace in the Smokies"*. The query becomes hard filters (destination, guests, bedrooms, max price, pets) and soft preferences (property type, amenities, features, "vibes"). The app then ranks 144 synthetic listings.
2. **Trace every answer to its sources.** The query highlight shows which words produced which constraint. The grounded answer puts a citation on each claim. Click a citation or **Trace** to open the source record with the supporting fields highlighted. Vibe claims such as *romantic*, *quiet* or *kid-friendly* cite the exact guest review behind them.
3. **Run the evaluation set** (tab 2). 26 labeled queries report top-1 accuracy, Precision@5, Recall@10, the hard-requirement violation rate and zero-result queries. Results are broken down by query type, and you can open any row to inspect it. Two queries are deliberately *known-hard* (negation, open-ended numbers), so the report shows real limitations.
4. **Compare two configurations side by side** (tab 3). Pick any two presets, or switch individual components on or off (NL parser, synonyms/paraphrases, review evidence). You get live results for one query plus metric deltas over the whole eval set and the list of queries that flip from pass to fail.

| Preset | What it does | Top-1 accuracy (seed 2027) |
|---|---|---|
| A · Keyword baseline | TF-IDF keyword match over listing text | 58% |
| B · NL parser, canonical terms | Structured parse with no synonyms and no review grounding | 58% |
| C · NL parser + synonyms + review evidence | Full pipeline | 96% |

## How it works
- `seed.py` uses only the Python standard library and is deterministic. It generates `data/listings.json` (144 fictional listings in 12 destinations, each with 3 reviews) and `data/eval_set.json`. Gold labels come from hidden ground truth inside the seed script, including "vibes" that appear only in review text, so the labels are independent of the search engine.
- `engine.js` holds the query parser, the hard-filter and soft-ranking logic, the keyword baseline, grounded-answer generation and the eval metrics. It runs entirely in the browser. A transparent rule-based parser takes the place of an LLM query-understanding step: every decision can be inspected, results are reproducible, and the demo needs no paid service or API key. In a production version, an LLM would emit the same structured-constraint schema.
- `index.html`, `app.js` and `styles.css` are the static UI. There is no build step and nothing to install.

## Run locally
```bash
python3 seed.py                 # (re)generate synthetic data; optional, data/ is committed
python3 -m http.server 8000     # then open http://localhost:8000
```
Use `python3 seed.py --seed 7` to get a different but still deterministic dataset. The engine also runs under Node, e.g. `node -e "const E=require('./engine.js'); ..."`.
